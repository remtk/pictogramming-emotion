🌟 基本の学習手順

        

          

            1
            

              問題に挑戦する
              
画面上部の「🧩 みんなの問題を解く」を押すと、出題数（3問・5問・10問）とお好きな難易度（初級・中級・上級）を選んで問題セットをスタートできます。

            

          

          

            2
            

              プログラムを入力して「実行 ▶」
              
中央のエディタに命令を入力し、「実行 ▶」を押すとピクトグラムがアニメーションします。「📂 サンプル」から模範コードを読み込むこともできます。

            

          

          

            3
            

              判定とヒント・ギブアップ
              
お題通りの動作ができると「できました！」になります。困った時は「💡 ヒント」を見たり、難しすぎる時は「🏳️ ギブアップ」で解答を確認して次に進めます。

            

          

        


        
💡 画面の便利な機能

        
    
          
  • 🤖 問題を生成: 課題エリア右上の「問題を生成」ボタンを押すと、AIに新しい問題を自動作問させることができます。
    • 
          
  • リサイズ自由: コード入力欄やコンソールパネルの右下をマウスでドラッグすると、好きな大きさに広げられます。
    • 
          
  • ドラッグ移動: 停止中は、画面上のピクトグラムやアイテムを直接マウスで掴んで動かすことができます（座標確認も可能）。
    • 
          
  • 感情パレット: 左下の色とりどりのチップを押すと、その感情のコードがワンクリックで入力されます。

🕺 ポーズをつくる・移動する

        

          

            
              
命令の書き方効果と解説

            
            
              

                R 部位 角度
                指定した部位を瞬時に回転させます。
例: R 左上腕 90（腕を時計回りに90度）		
              

              

                RW 部位 角度 秒
                指定秒数をかけてなめらかに回転アニメーションします。
例: RW 右上腕 -90 1		
              

              

                M x y
                ピクトグラム全体を座標(x, y)分だけ瞬時に平行移動します。
例: M 50 0（右へ50進む）		
              

              

                MW x y 秒
                指定秒数をかけて歩行しながら平行移動します。
例: MW 60 0 1		
              

              

                WAIT 秒
                指定した秒数だけその場で一時停止（待機）します。
例: WAIT 1（1秒待つ）		
              

              

                REPEAT 回数 ... END
                ENDまでの処理を指定回数繰り返します。
例: REPEAT 4 ... END（正方形の描画など）		
              

              

                LET 変数名 値
                変数に数値を代入・更新します。
例: LET LEN 30 / 参照は [LEN] や [LEN + 10]		
              

              

                IF [条件式] ... END
                条件式が真（正しい）のときだけ処理を実行します。
例: IF [SCORE >= 80] ... END		
              

            
          

        

        

          ※ 部位名の指定ルール（R・RW命令、IK・IKW命令どちらでも共通して使えます）:
          

            ・上腕（右上腕 / 左上腕 / 右腕 / 左腕）: 「肩から先（腕全体）」を動かします。

            ・上腿（右上腿 / 左上腿 / 右脚 / 左脚）: 「股関節から先（脚全体）」を動かします。

            ・前腕（右前腕 / 左前腕 / 右ひじ / 左ひじ）: 「ひじから先」を曲げます。

            ・下腿（右下腿 / 左下腿 / 右ひざ / 左ひざ）: 「ひざから先」を曲げます。

            ・英字記号（BODY, RUA, RLA, LUA, LLA, RUL, RLL, LUL, LLL）でも同じように指定できます。
          

        


        
        
💡 初心者向け：よく使う組み合わせレシピ

        
プログラミングでは、命令を単体ではなく「セット」で組み合わせることで賢い動作が作れます。


        

          
          

            ① 【超定番】変数（LET）と条件分岐（IF）の組み合わせ
            
「点数や数値によってピクトグラムのセリフや感情を変えたい」ときは、LET（数字を箱に入れる）とIF（もし〜なら）をセットで使います。

            

              LET SCORE 80

              IF [SCORE >= 70]

                EMOTION JOY 0

                SP "合格です！"

              END
            

            

              ・LET SCORE 80 で SCORE という名前の箱に「80」を入れます。

              ・IF [SCORE >= 70] で「もし箱の中身が70以上なら、ENDまでの命令を実行」します。

              ・※条件式や変数は必ず 半角の角括弧 [ ... ] で囲むのがルールです。
            

          


          
          

            ② 【だんだん変化】変数（LET）と繰り返し（REPEAT）の組み合わせ
            
「繰り返すたびに、だんだん進む距離を増やしたい（階段やうずまき等）」ときに使います。

            

              LET STEP 20

              REPEAT 3

                MW [STEP] 0 0.4

                LET STEP [STEP + 20]

              END
            

            

              ・1周目: MW 20（20進む）

              ・LET STEP [STEP + 20] で箱の中身を 20 ➔ 40 に増やします。

              ・2周目: MW 40（40進む）と、回数を重ねるごとに大きく動くようになります。
            

          


          
          

            ③ 【重要なお作法】動かした腕を「元の姿勢に戻す」組み合わせ
            
腕や脚を動かしたあと直立姿勢に戻すときは、「0度にする」のではなく「反対向き（マイナス）の角度」を指定します。

            

              R 右上腕 -90

              WAIT 0.5

              R 右上腕 90
            

            

              ・ピクトコードの回転（R / RW）は「現在の角度からの変化量」です。

              ・R 右上腕 -90 で腕を上げたら、反対のプラス 90 を指定すると元の0度に戻ります。
            

          

        

      


      
      

        
🎭 感情表現命令（エディション特別機能）

        
人型ピクトグラムが表情・ポーズ・オーラ色を一斉に変化させて豊かな感情を表現します。

        

          EMOTION 感情名 [秒]
        

        

          

            
              
感情名（日本語 / 英語）オーラ色特徴

            
            
              

                喜び (JOY)
                琥珀色（オレンジ）
                満面の笑顔になり、両腕をパッと開いて喜びを表します。
              

              

                悲しみ (SAD)
                青藍色（ブルー）
                困り眉と口になり、両腕をしょんぼり下ろしてうつむきます。
              

              

                怒り (ANGRY)
                朱赤（レッド）
                つり眉でプンプン怒り、腕を突き出して抗議ポーズを取ります。
              

              

                驚き (SURPRISE)
                紫色（パープル）
                目を丸くして驚き、腕をすぼめて飛び上がります。
              

              

                普通 (NORMAL)
                標準（ダークグレー）
                通常の真顔・標準の直立ポーズへ戻します。
              

            
          

        

        
※ 感情パレットのチップをクリックすると、コード入力欄に自動挿入されます。

      


      
      

        
🎨 図形を描く（ピクトグラフィックス）

        

          

            
              
命令説明

            
            
              
PEN DOWNペンを下ろします。この後の移動（M/MW）の軌跡が線として描かれます。

              
PEN UPペンを上げます。移動しても線を描かなくなります。

              
PEN COLOR "#色"描画する線の色を変更します。例: PEN COLOR "#E74C3C"

            
          

        


        
💬 セリフ・アイテム・IK（座標指定）

        

          

            
              
命令説明

            
            
              
SP "文字"吹き出しを表示してセリフを喋らせます。例: SP "こんにちは！"

              
ITEM 種類 x y指定座標にアイテム（リンゴ, 星, ハート, 剣, ボール）を配置します。

              
IMW 種類 x y 秒配置したアイテムを指定秒数かけて平行移動させます。

              
ITEM CLEAR配置したアイテムをすべて画面から消去します。

              
IK 部位 x y指定した腕・脚の手先・足先を座標(x, y)へ伸ばします（右腕/右上腕, 左腕/左上腕, 右脚/右上腿, 左脚/左上腿など）。

              
IKW 部位 x y 秒指定秒数をかけて手先・足先を座標(x, y)へ伸ばすアニメーションを行います。

            
          

        

      


      
      

        
💡 問題のクリア判定とお作法

        

          ✅ 正解（できました）になる条件
          
問題文で求められた「ポーズ（角度）」「感情」「セリフ」「描画した図形」が完成状態および手順と合致していれば合格になります！

        

        

          🎯 動作順序の大切さ
          
「右に行ってから上に行く」や「感情を変えてからセリフを言う」など、動作の順序も正しく組み立てることで合格判定になります。

        

        

          ✏️ 描き終わりの PEN UP について
          
図形を描き終えた最後に PEN UP を書き忘れても、図形が完成していれば合格になります。ペンを上げるとピクトグラムが正面を向くため、より綺麗な仕上がりになります！

        

        

          💡 ヒントと 🏳️ ギブアップの活用
          
解き方に迷ったら「💡 ヒント」ボタンで手がかりを確認できます。どうしても解けない場合は「🏳️ ギブアップ」を押すと模範解答を確認でき、そのまま次の問題へ進むことができます。

        

        

          🧩 命令を組み合わせて使うコツ（LETとIFなど）
          
「LET（変数に数字を入れる）」と「IF（もし〜なら）」はセットで使います。詳しい書き方は「💃 動作・制御命令」タブの後半にある『組み合わせレシピ』に具体例が載っていますので、ぜひ参考にしてください！
